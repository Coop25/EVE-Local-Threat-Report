EVE Local Threat Report

Paste one pilot name per line, then pull recent zKillboard activity and flag characters who look dangerous. This tool checks ship and pod kills for the current month plus a selectable number of previous months, and links each pilot directly to their zKillboard profile.
Tip: keep the page limit low if you are checking a large local list. This version queries zKillboard by calendar month, so it is best for fast threat snapshots rather than exact rolling 60 or 90 day windows.
